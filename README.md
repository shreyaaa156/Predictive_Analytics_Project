# Predictive Analytics Using Historical Data

## Objective
Build a predictive model to forecast future trends using historical sales data.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm
Linear Regression

## Dataset
Historical Sales Dataset

## Features
- Historical Data Analysis
- Trend Visualization
- Regression Modeling
- Future Forecasting
- Prediction Visualization

## Output
Forecast future sales trends based on historical data.

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the project:

python predictive_analytics.py
